### Selected work

- **[Distributed Workflow Engine](https://github.com/dannyp-dev/distributed-workflow-engine)**: A Go task engine for asynchronous jobs, with durable PostgreSQL state, Redis Streams consumer groups, retries, task reclamation, and gRPC worker coordination. Runs locally with Docker Compose.
- **[Concurrent Ticketing Platform](https://github.com/dannyp-dev/concurrent-ticketing-platform)**: A Next.js and TypeScript ticket reservation prototype with event browsing, an interactive seat map, timed holds, and simulated checkout. A Spring Boot and PostgreSQL backend is planned.
- **[Internship Job Watcher](https://github.com/dannyp-dev/internship-job-watcher)**: A Python tool that monitors internship feeds, filters and deduplicates listings, and sends Telegram alerts. Uses Cloudflare scheduling and GitHub Actions, with source-health checks and notification history.
- **[UF Scheduler](https://github.com/dannyp-dev/UF-Scheduler)**: A UF course-planning project with nonoverlapping schedule generation, custom events, semester plans, and prerequisite visualization. [Backend repository](https://github.com/dannyp-dev/UF-Scheduler-Backend).
- **[Algorithm Studio](https://github.com/dannyp-dev/Algorithm_Visualizer)**: Write Python in the browser and explore algorithm execution through a reversible visual timeline. Built with TypeScript, Pyodide, Web Workers, and D3.
- **[FreshMeals4U](https://github.com/dannyp-dev/FreshMeals4U)**: A meal-planning app that turns available ingredients into recipe ideas, with photo-based ingredient detection and a meal calendar.
